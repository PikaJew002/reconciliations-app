# New-user onboarding thoughts

Working notes for what a new user should do first. Not a finished product spec — update this as the flow gets clearer.

The goal of this first pass is enough history to categorize, learn recurring rules, and then set paycheck and bill plans. A month and a half of imports is enough to see one full cycle plus the late/early posts that plans are meant to catch.

## First-run sequence

1. **Import bank transactions** — about 1.5 months back.
2. **Import orders** — about 1.5 months back (Amazon, Walmart, etc.).
3. **Add categories** — income, bills, and expenses the user actually uses.
4. **Categorize those imported transactions.** While doing that, create rules for anything that will recur (paychecks, utilities, subscriptions) so the next import does it automatically.
5. **Set planned paychecks and bills** — after the history and rules exist, so plans can be based on real transactions.

## Open questions

- Does category setup belong before imports, or is “add as you categorize” better?
- Should onboarding prompt the 1.5-month window, or just say “recent history”?
- After plans exist, what is the next “you’re set” moment — first successful import match?
